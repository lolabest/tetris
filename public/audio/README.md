# Optional licensed music

To use **Dear Simon** (or another licensed track) as the in-game loop:

1. Confirm you have a legal license to use the recording in this game.
2. Place the file here as:

```text
public/audio/dear-simon.mp3
```

If this file is missing, Piano Blocks automatically uses an original
procedural piano-and-saxophone composition. No console errors are raised
when the optional file is absent.

Do not commit copyrighted audio unless you own or have licensed the rights.
