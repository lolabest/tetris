# Changelog

All notable changes to Piano Blocks will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-04

### Added

- Complete falling-block puzzle engine with seven-bag randomizer, hold, ghost piece, and SRS-inspired wall kicks
- Premium piano-themed Canvas UI with start, pause, and game-over flows
- Procedural Web Audio piano feedback isolated from the game engine
- Keyboard and touch controls with accessibility support
- High-score and settings persistence via localStorage
- Vitest unit tests and Playwright smoke test
- Documentation, MIT license, and GitHub Actions CI
